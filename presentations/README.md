# 발표 자산

**읽는 사람**: 이 저장소의 내용을 팀에 발표하거나, 지난 발표 자료를 다시 보려는 사람.

`docs/`가 소유한 설계 판단을 청중용으로 렌더한 **파생물**이다. 두 곳이 어긋나면 `docs/`가
맞다. 발표 자료를 고쳐서 설계가 바뀌지 않는다.

| 자료 | 다루는 것 | 장수 |
|------|-----------|------|
| [`2026-09-iac-asset/`](2026-09-iac-asset) | iac-module-library, 팀의 IaC Asset. 자산 · GitOps 허브-스포크 · AWS에서 Azure로 이식 · Gateway API 전환 | 24 |

## 디렉토리 이름

`<연월>-<주제>` 형식이다. 연월은 자료를 쓴 시점이고, 읽는 사람이 안에 적힌 모듈 버전·요금·
지원 일정을 얼마나 믿을지 판단하는 기준이 된다. 발표 자료는 그 시점의 스냅샷이라 `docs/`와
달리 날짜가 정보다.

버전 번호는 경로에 넣지 않는다. 같은 자료를 고치면 같은 디렉토리에 커밋하고, 이력은
`git log`가 갖는다. 새 주제로 발표하면 디렉토리를 새로 만든다.

## 파일

| 파일 | 무엇 |
|------|------|
| `slides.html` | 발표 슬라이드. 브라우저로 열고 ← → 또는 스크롤로 넘긴다. 외부 의존성이 없는 단일 파일이다 |
| `article.md` | 같은 내용의 기술 문서. 슬라이드가 생략한 근거와 출처를 담는다 |

`article.md`는 `docs/`의 400줄 제한을 받지 않는다. 발표 원고는 그 규칙이 상정한 종류의
문서가 아니라서 `docs/` 밖에 둔다.

## PowerPoint로 변환

```bash
python3 scripts/build-deck-pptx.py presentations/2026-09-iac-asset/slides.html deck.pptx
```

`.pptx`는 커밋하지 않는다. 3MB 바이너리를 저장소에 쌓는 대신 스크립트를 남겨 필요할 때
재생성한다. 슬라이드를 이미지로 배치하므로 PowerPoint에서 본문을 고칠 수 없다. 내용을
바꿀 때는 `slides.html`을 고치고 다시 돌린다.

python-pptx와 Google Chrome이 필요하다.
